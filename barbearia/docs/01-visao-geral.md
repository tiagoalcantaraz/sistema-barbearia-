# Visão Geral
Sistema web para clientes agendarem serviços da barbearia e para o barbeiro acompanhar a agenda.
**Tecnologias:** Python, Flask, SQLite, HTML/CSS.
**Telas:** Início (serviços), Agendar, Painel (lista, concluir, cancelar, faturamento).
**Fora do escopo (futuro):** login, pagamento online, notificações por WhatsApp, múltiplos barbeiros.
