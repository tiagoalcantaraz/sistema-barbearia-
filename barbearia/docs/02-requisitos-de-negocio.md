# Requisitos de Negócio
- RN-01: Clientes devem agendar sem precisar de cadastro ou senha.
- RN-02: O barbeiro deve ver todos os agendamentos ordenados por data e hora.
- RN-03: O barbeiro deve poder concluir ou cancelar agendamentos.
- RN-04: Reduzir conflitos e esquecimentos de horário.
- RN-05: Mostrar o faturamento dos atendimentos concluídos.
